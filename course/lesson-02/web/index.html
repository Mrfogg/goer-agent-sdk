lesson 02

让 Agent 记住你

记忆不在对话里：清空历史之后它还认得你，因为记忆存在对话之外

先让它认识你

比如「我是做财务分析的，以后回答都用中文，尽量简短」——模型会调用 memory_write 把这件事写进记忆库。

然后点右上角「新会话（保留记忆）」，再问一句「我是做什么的？」。历史已经清空，但它仍然答得出来。

回车发送 · Shift + 回车换行 · 运行中点「停止」会中断这一轮 run

记忆库 0 条

存在 memories.db 里（SQLite），进程重启也还在。 「新会话」不会动它，只有「清空记忆」才会。

还没有任何记忆

这一轮发生了什么

  1. 1 发送请求 历史 + 记忆一起进 system prompt
  2. 2 模型思考 reasoning / content
  3. 3 调用工具 记忆的读写删都在这
  4. 4 end tool 交付 finish 成功 → run 结束

看这三点

  • 历史 ≠ 记忆。每轮开头那条 context 事件报两个数：带上的历史条数、记忆库条数。点完「新会话」再问一次，历史是 0，记忆还在。
  • 没调用就没记住。记忆只有 memory_write 一个写入口。模型这一轮没调它，说过的任何话下一轮都不存在。
  • 删不删不是模型说了算。memory_forget 要求模型引用用户原话，服务端会核对——你没说过「忘掉」，它就删不掉。
