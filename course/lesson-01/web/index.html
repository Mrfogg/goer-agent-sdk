先问一句试试

比如「现在几点？」——模型会调用 now 工具拿时间，再用 finish 交付答案。

留意右边：哪一步发生了什么、以及原始 SSE 事件长什么样。

回车发送 · Shift + 回车换行 · 运行中点「停止」会中断这一轮 run

这一轮发生了什么

  1. 1 发送请求 POST /api/chat
  2. 2 模型思考 reasoning / content
  3. 3 调用工具 普通工具：结果写回 transcript
  4. 4 end tool 交付 finish 成功 → run 结束

看这三点

  • 文本不结束任务。模型如果只用文字回答，会被退回去重新调用工具——右边第 2 步会重复出现。
  • 工具是两条通道。工具卡片来自 ToolResult.Events，前端能看到，但模型上下文里没有。
  • 答案来自 end tool。最后那段标注「交付答案」的文本，是 finish 的 ModelContent，不是模型最后的自言自语。
